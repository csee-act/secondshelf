## Quick interview guide

Talk with someone who recently moved or will move soon. Record date/context and permission before using an anonymous quote.

1. Tell me about the last item you could not decide whether to keep.
2. What did you do, and what made that difficult?
3. How did you track it or try to pass it on?
4. Try deciding on one real item in SecondShelf. Where did you hesitate?
5. What would make you return before your move? What would stop you?

Report participant count, actual observations and contradictory feedback. An experiment that disproves an assumption is useful evidence.
